ICDS AutoDesk – Installation Guide

Welcome to ICDS AutoDesk Setup

Before you continue with the installation, please carefully read the following instructions to avoid any issues:

------------------------------------------------------------
System Requirements
------------------------------------------------------------
- Operating System: Windows 10 / 11 (64-bit recommended)
- Python: Version 3.7 or above (if required by your configuration)
- RAM: Minimum 4 GB (8 GB recommended for large Excel files)
- Disk Space: At least 500 MB free

------------------------------------------------------------
⚡ Important Notes Before Installation
------------------------------------------------------------
1. Close All Excel Files
   - Ensure that no Excel files are open during installation.
   - This prevents file locking issues when ICDS AutoDesk integrates with Excel.

2. Installation Location
   - By default, ICDS AutoDesk will install in:
     C:\Program Files\ICDS AutoDesk
   - Temporary files will be stored in your local AppData folder.

3. Permissions
   - Administrator privileges are required by default for full system integration.
   - Setup and application will automatically request elevated permissions.


4. Internet Requirement
   - An active internet connection may be required for the first-time setup of dependencies.

------------------------------------------------------------
🚀 Installation Steps
------------------------------------------------------------
1. Run the ICDS AutoDesk Setup installer.
2. Follow the on-screen instructions and select the installation directory (default recommended).
3. Wait until the setup completes.
4. Launch ICDS AutoDesk from the Desktop shortcut or Start Menu.
